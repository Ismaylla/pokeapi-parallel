# PokeAPI Parallel Downloader

Projeto da disciplina de Sistemas Paralelos e Distribuídos.

## Objetivo

Comparar abordagens sequenciais e paralelas para download de imagens da PokeAPI utilizando:

- Sequential
- Threading
- Multiprocessing
- concurrent.futures

## Tecnologias

- Python
- requests
- threading
- multiprocessing
- concurrent.futures
